## 回程是不是真三网 GIA

路由结构是这样：

- 电信去程：CN2（AS4809）
- 联通去程：CN2（AS4809）
- 移动去程：CMIN2（AS58807）
- 三网回程：全部 CN2 GIA（AS4809）

多篇测评做过回程 traceroute，北京、上海、广州、成都四个方向，电信、联通、移动的落点都在 CN2 链路上。移动去程走 CMIN2、回程又被拉进 GIA，这是这条线路成本最高的地方，也是同价位产品普遍做不到的部分。

GIA 解决的是晚高峰。普通 163 骨干在 20:00–23:00 丢包明显，延迟能从 150ms 冲到 400ms 以上；GIA 绕开这段拥塞，延迟曲线基本是平的。

延迟数据各家测点不同，不能合成一个数字，分开看：

- 日本多个据点 ping 洛杉矶：约 100–130ms，夜间与拥塞时段未见明显丢包（单篇日本向测评口径）
- 中国大陆电信、联通：约 130–170ms，移动略高（多用户测评汇总口径）
- 洛杉矶直连测：130–160ms（单机实测）
- 国内到洛杉矶：150–180ms（另一篇测评口径）

同一条线路不同人测出差 50ms，主要是测点位置和是否经过中转造成的。拿它做游戏服、语音这类实时性要求高的东西不合适，150ms 起步的物理距离摆在那儿，GIA 也改不了。

有测评记录到单线程测速时电信个别节点跑不满或者短暂断流。跨海线路偶发这种情况不算罕见，但对单线程稳定性要求极高的场景要提前有数。

## 下单前最容易被绊住的六条政策

这几条比参数更影响实际体验，也是前排文章最容易漏掉的。

**流量超了不停机。** 1000 GB 用完后限速到 2Mbps，机器继续在线，SSH、文字类工作、低频请求都能撑住。想靠它接着看 4K 不现实。这个政策对个人节点友好，至少不会某天突然断网。常规款超量后降到 4–10Mbps，比活动款宽松。

## 几个常见问题

**现在还能买到吗？**
MALIBU 是限量特供，不定期补货，售罄即下架，没有常规在售状态。第三方观察到的补货节点集中在大促期间（黑五、双十一、圣诞元旦），这是观察，不是官方承诺。

**1GB 内存能跑什么？**
Debian 或 Ubuntu 最小安装加 Nginx 跑静态站，或者一个轻量代理，很轻松。WordPress 加 MySQL 能跑起来但要配 swap，并发一上来就吃紧。

**和 EB 系列怎么选？**
同机房 EB 系列走 CMIN2 / AS9929，入门活动款更便宜（1 核 1G / 20G / 1000 GB 约 $39.9/年），回程不是 GIA。电信用户体验差距最明显，联通、移动差距小一些。预算卡得紧、主要用移动联通，可以看 EB；主力是电信，MALIBU 这 $10 差价花得值。

不需要，$49.9 就是直接售价。网上流传的优惠码基本属于 EB、T1 以及香港、东京产品线，和 MALIBU 无关。
